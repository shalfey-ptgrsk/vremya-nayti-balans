# Время найти баланс

React + TypeScript + Tailwind CSS + Motion.

Сайт: https://shalfey-ptgrsk.github.io/vremya-nayti-balans/

## Разработка и публикация

Установка: `npm ci`. Разработка: `npm run dev`. Проверки: `npm test`. Сборка: `npm run build`.

GitHub Pages публикует папку `docs` ветки `main`. Для обновления после проверок скопировать содержимое `dist` в `docs`, сохранить `.nojekyll`, затем отправить изменения в GitHub.

Шаблон альтернативной публикации через Actions сохранён в `scripts/pages-workflow.yml`. Сейчас он не активен: публикация папки docs не требует дополнительных разрешений workflow.
